Capsule Radar

Live-ADS-B-Flugradar · deutsche Version · runde Waveshare-ESP32-S3-AMOLED-Boards

Firmware direkt aus dem Browser aufspielen – ohne Toolchain, ohne PlatformIO.

Bitte Chrome oder Edge am Computer verwenden (Web Serial nötig). Zum Flashen muss diese Seite über HTTPS geladen werden.
Installiert Firmware v__FWVER__
Wählen Sie das Board, das Sie wirklich haben – mit dem falschen Image bleibt der Bildschirm schwarz (harmlos: einfach das richtige aufspielen).
  1. Board mit einem USB-C-Datenkabel an den Computer anschließen.
  2. Auf Installieren klicken und den Anschluss USB JTAG/serial (oder USB Serial) wählen.
  3. Beim ersten Mal Erase device (Gerät löschen) + Install wählen.
  4. Nach dem Neustart mit dem Handy das WLAN CapsuleRadar-Setup verbinden und Ihr WLAN eintragen.
  5. Standort und alles Weitere danach unter http://capsuleradar.local/ einstellen.
